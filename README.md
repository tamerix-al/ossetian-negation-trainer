
# Ossetian Negation Trainer

Интерактивный тренажёр отрицательных частиц осетинского языка, разработанный на Python.

Учебный проект по дисциплине «Продвинутое программирование».

## Описание

Приложение использует корпус осетинских предложений с размеченными отрицательными частицами `ма` и `нӕ`.

Пользователь выбирает пропущенную частицу в предложении, после чего программа сравнивает ответ с исходным корпусным примером.

Приложение также позволяет просматривать корпус, искать предложения и анализировать статистику употребления частиц в собранной выборке.

## Функциональность

### Тренажёр
- Тесты на 5, 10 или 20 вопросов.
- Случайный выбор предложений.
- Автоматическое скрытие целевой частицы.
- Проверка ответов.
- Подсчёт результата.
- Просмотр исходного контекста.

### Корпус
- Поиск по осетинскому тексту.
- Фильтрация по частицам и источникам.
- Просмотр предложений и полных контекстов.

### Визуализация
1. Столбчатая диаграмма количества вхождений каждой частицы.
2. Диаграмма распределения длины предложений по частицам.

Графики интерактивные и учитывают выбранные фильтры.

## Архитектура

В проекте реализованы четыре класса:

- `NegationExample` — хранит отдельный корпусный пример и формирует предложение с пропуском.
- `NegationCorpus` — загружает CSV, проверяет и хранит примеры.
- `QuizSession` — управляет вопросами, проверяет ответы и подсчитывает результат.
- `CorpusStatistics` — рассчитывает статистические показатели.

Используется композиция: `NegationCorpus` содержит объекты `NegationExample`, а `QuizSession` работает с корпусом.

В классах переопределён специальный метод `__len__`, позволяющий получать количество элементов через функцию `len()`.

## Установка и запуск

Требуется Python 3.10 или новее.

Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

Запустить приложение:

```bash
python -m streamlit run app.py
```

Открыть в браузере:

http://localhost:8501

На Windows вместо `python` можно использовать `py`.

## Тестирование

Запуск автоматических тестов:

```bash
python -m unittest -v
```

## Данные

Исходный датасет содержит 248 записей с осетинскими предложениями.

247 записей проходят формальную проверку разметки. Для тренажёра используются 235 примеров, удовлетворяющих ограничению длины предложения.

Датасет составлен для исследования употребления отрицательных частиц и не является репрезентативной случайной выборкой осетинского языка.

Правильный ответ в тренажёре определяется по исходному корпусному примеру. Альтернативная частица не обязательно грамматически невозможна.

## Ограничения

- Программа не выполняет автоматический грамматический анализ.
- Разметка отрицания не прошла полную ручную верификацию.
- Статистика характеризует только имеющийся датасет.
- Результаты теста хранятся в рамках пользовательской сессии.
