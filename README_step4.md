# Этап 4 — корпус и статистика

В приложении появились три вкладки: **Тренажёр**, **Корпус**, **Статистика**. Логика теста не менялась.

## Установка обновления

Скопируйте `app.py` и `requirements.txt` поверх прежних файлов, добавьте `corpus_stats.py` и `test_statistics.py` в корень проекта. Исходный CSV, `quiz.py`, `models.py`, `corpus.py` менять не нужно.

В терминале VS Code (Windows):

```powershell
py -m pip install -r requirements.txt
py -m unittest -v
py -m streamlit run app.py
```

При других настройках Python используйте `python` или `python3` вместо `py`.

## Что реализовано

- **Тренажёр**: 5, 10 или 20 случайных вопросов с обратной связью и финальным счётом.
- **Корпус**: поиск по тексту, фильтрация по форме частицы и источнику, таблица и просмотр полного контекста.
- **Статистика**: столбчатая диаграмма вхождений по формам частиц и box plot распределения длины предложений. Оба графика используют фильтры из боковой панели.

Графики описывают только текущую выборку, которая собиралась целенаправленно, а не частотности во всём осетинском языке. Слова считаются приблизительно; длина берётся из одного предложения с целевой частицей (включая длинные предложения, исключённые из теста).

## Объектная модель и требования

- `NegationExample` — модель корпусного примера.
- `NegationCorpus` — чтение и проверка CSV, переопределение `__len__`.
- `QuizSession` — тестирование и проверка ответа.
- `CorpusStatistics` — статистические расчёты без зависимостей от интерфейса.

В `NegationCorpus` хранятся объекты `NegationExample` (композиция), а `QuizSession` работает с `NegationCorpus`. Имеются две визуализации Plotly. Все формальные требования выполнены.

Исходный CSV содержит 248 строк. Строка с ID 44 пропускается проверкой, поэтому доступно 247 примеров. Из них для теста допускаются только короткие примеры — не более 200 символов после извлечения предложения.
